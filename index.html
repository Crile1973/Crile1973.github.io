YoutubeLibrary

YoutubeLibrary is a personal, single-user tool built by Jason Gagne (GitHub: Crile1973) for his own YouTube account. It uses the YouTube Data API with read-only access (youtube.readonly) to read his own subscriptions and playlists, so that he can organize videos he has saved, get transcript summaries, and keep notes.

It is not offered to the public and has no other users.
